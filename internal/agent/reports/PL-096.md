# PL-096: a suggestion chosen by the row's value never falls back to a fixed position

Owner: T2 (DeepSeek) · Reviewer: T1 · Branch `pl-096` (from `main`)

## Status: done — both gates green, no fixture output changed

## The change

`packages/compiler/parameterize.py`, in `parameterize_candidate` and its helpers. Nothing else
changed: no compiler pipeline stage, runner, extension or schema.

After the rungs are templated, a click whose ladder names a suggestion option
(`action == "click"` and any rung with `role: option`, the same condition as
`compiler._is_option_click`) is trimmed when at least one rung now carries `{{row.`:

- every rung whose own text carries no `{{row.` template is dropped — a `css` path, a `testid`,
  or any other rung that still points at the recorded option;
- each dropped rung gets one warning:
  `dropped rung css "#user_id_0_0_0": it points at the recorded option, not the row's`;
- an option click with nothing templated ("Search More...") keeps its whole ladder;
- clicks that name no option (buttons, cells) are untouched, so their fixed rungs stay.

The rungs that remain keep their recorded order. `parameterize.py` now holds a local
`_is_option_click` because `compiler.py` already imports this module; importing back would be a
cycle. It reads the same rung field and role as `compiler._is_option_click`.

Helpers added: `_rung_names_row`, `_rung_label`, `_is_option_click`, `_drop_fixed_option_rungs`,
plus `ROW_TEMPLATE_MARKER` and `_LABEL_FIELDS`.

### The pilot's ladder, compiled

Replaying the PL-027 many2one recording (`fill "Priya"`, option click with
`role option "Priya Raman"` -> `css "#user_id_0_0_0"`, then the page's own fill) through
`compile_recording` now yields:

```
click-1 targets: [{"by": "role", "role": "option", "name": "{{row.salesperson_2}}"}]
warning: dropped rung css "#user_id_0_0_0": it points at the recorded option, not the row's
```

So a row naming a salesperson the list does not have misses the role rung and finds nothing; it
cannot fall through to the first suggestion.
