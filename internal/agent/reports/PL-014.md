### The bugs the end-to-end run found (and fixed)

The e2e suite earned its keep before it went green: it caught five defects in shipped code that the unit suites
and the scripted fake could not see. Each is fixed and committed in `4d5ca05`.

1. **The wire expiry used a monotonic clock.** `BrowserExecutor` stamped `expires_at` from
   `time.monotonic()`, while the extension compares it to `Date.now()`. Every command arrived looking decades
   expired, and every record parked with *"the command expired before it was received"*. Wall clock now.
2. **`_command` never carried the step's `url`.** A rendered `navigate` step reached the extension with no
   destination at all (*"the navigate step has no usable URL"*). It is rendered now, like every other field.
3. **A value source arrived as a bare literal.** `_render_value_source` returns the resolved value, which the
   extension refused (*"cannot resolve a value source of kind undefined"*). It now travels as
   `{kind: "constant", value: ...}` — which is also the honest boundary: the runner resolves values, the
   extension does not.
4. **`prepare` performed the action.** The extension's command handler resolved *and* performed for every
   command, so a commit's `prepare` would click Save and its `dispatch` would click Save again. A `prepare` now
   stops after resolving and hit-testing, sending no input (the plan's R2), and `navigate` is performed without
   resolving a ladder it does not have.
5. **`value_equals` compared against nothing.** `_render_condition` rendered every predicate except
   `value_equals`, so a condition's expected value was empty and a branch comparing a field against the record's
   own value matched the empty field instead. Both sides fixed: the runner renders the value source to a
   literal, and the extension reads it from the condition.

Items 1, 2 and 3 are worth T1's attention precisely because they were invisible to every green test: the fake
executor never inspects a step, and the extension unit tests inject a `runStep` stub. Only a real browser
against a real hub could fail them.

requirement 5 mandates behaviour that directly contradicts them.

rule on them.
