## What was done

Tests were written first and observed failing, then the four fixes landed and every targeted test
was observed passing.

1. **Route with a dot 404'd on refresh** — `services/api/main.py`: `SpaStaticFiles.get_response`
   now treats a path as an asset only when its suffix is in an `ASSET_SUFFIXES` allowlist

   answers `index.html`; `/api/` misses keep the API's JSON 404.
2. **Queued runs showed as "Running now"** — `packages/ledger/reads.py`: the Home `running` read
   is now `WHERE ru.status = 'running'` (was `IN ('queued', 'running', 'paused')`); comment and
   docstring updated to match.
3. **Developer message on Needs help** — `apps/web/src/lib/words.ts`: `operatorNote` no longer
   surfaces the API's 503 `detail` (which names `PROCESSLENS_OPERATOR_ID`). It returns the fixed
   sentence "Actions are turned off until an operator is set up. Ask your admin." The unused
   `OPERATOR_PROBLEM` constant was removed; the Needs help and Run detail call sites are unchanged.
4. **Slow Home count** — new `db/migrations/0007_transitions_at_index.sql` with the one-line
   `CREATE INDEX IF NOT EXISTS run_record_transitions_tenant_at ON run_record_transitions (tenant_id, at);`
