# PL-103 report: the recorder forgives a normal person's mistakes

Status: items 1–6 built and tested; item 7 (clumsy-user e2e) is owed in the combined e2e run.

## What changed

1. **Open tabs.** Start teaching on a tab with no recorder puts one in (`chrome.scripting`, all
   frames; `scripting` permission added) and pings again; the refresh line only when that fails. A
   tab the person switches to while recording gets a recorder the same way (`tabs.onActivated`). The
   content script keeps one live recorder per frame, and replaces one orphaned by an update.
2. **Empty space.** A click on an element with no action role that holds fields, or that is only a
   long run of page text with no name of its own, is not recorded (`isEmptySpace`).
3. **Tab.** Tab is recorded only when the field's suggestion list is open (Odoo picks the
   suggestion); from a plain field it is dropped. The existing keypress test that said Tab is always
   a step was changed to the new rule.
4. **Names.** `makeEvent` cuts a step name to 120 characters (the schema's `step_name`); the compiler
   does the same for any step, so older extensions are covered too. Target names are templates (up to
   2000) and are left alone, so the ladder still matches the element's full name.
5. **Check before saving.** After Stop, the step list shows a problem on its own row with the fix:
   a click on a page area → **Remove**; teaching that began by typing on a new-record form
   (`/new`, `view_type=form`, `/create`) → **Start over** (the Clear button). A public form that is
   simply where the task starts is not flagged.
6. **One bad step never hides the save.** A schema refusal now starts with
   `Step N ("name") can't be saved as it was recorded. Remove it with × and save again.`, and the
   popup shows that sentence under Save; the engine's lines stay under Notes for support.
