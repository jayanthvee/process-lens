# PL-037 report (T1): fixes from the owner's real-browser test on Odoo

**Status:** done.

The owner recorded a lead-entry task by hand on a local Odoo CRM. A 7-row CSV then ran in their own Chrome, with the owner working in other tabs: **7 of 7 rows ended Done or Already there.** Every bug below was found in that session. None were reachable from the e2e harness, which always uses one fresh foreground tab, one Connect and a clean recording.

## The changes
1. **Typing over a page-filled field is kept** (`packages/compiler/coalesce.py`).
   - `coalesce_fills` merged the person's typing into the page's earlier fill, but kept the earlier entry's `page_set` flag. The typed value was then dropped as page-set.
   - The merged step now takes the later entry's flags and adds up the keystrokes.
2. **A contact picked before typing is kept** (`packages/compiler/compiler.py`).
   - `_settle_suggestion_boxes` dropped any option picked before typing in the box.
   - Now only a box's own prompt is dropped ("Start typing…", "Search more…", "No records", trailing "…").
3. **The save check counts the first entry.**
   - `_infer_assertion_from_fills` builds `text_count_increases` from the first picked option that isn't a hint, or from the first templated fill.
   - Without fixes 1–3, the owner's recording was refused at save: "commit step click-4 has no assert_after".
4. **One column per field in the popup** (`apps/extension/src/popup/make-recipe.ts`).
   - A chain of fills on one field that starts with a page-set fill now offers only its last value as a spreadsheet column.
   - Before, the popup offered half-typed values, such as `p@…testa`.
5. **The work window** (`apps/extension/src/background/service-worker.ts`, `bindActiveTab`). Connect used to bind the *active* tab, which is the dashboard or a `chrome://` new-tab page the debugger can't attach to.
   - **First fix: a background tab.** Chrome doesn't draw hidden tabs, so Odoo's OWL never rendered: "19 element(s)", and "no animation frame arrived".
   - **Now: a separate normal window** sized to the right half of the person's own window.
     - If Chrome refuses those bounds, it opens a plain window.
     - If that fails, it opens a new active tab.
     - **It never binds a tab the person is using.**
6. **The demo restarts its worker when Chrome reconnects** (`scripts/demo.py`). A worker bound to the old session kept pausing runs as `executor_disconnected`.
