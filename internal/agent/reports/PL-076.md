# PL-076: "Use for a task" carries the cleaned CSV over

Owner: T2 (GLM) · Reviewer: T1 · Branch `pl-076` · Web app only

## Status: **done — all gates green**

"Use for a task" now hands the cleaned document to the task a person picks, and the run page
uploads those rows through the very same path a picked file takes. No API changes.

## The change

1. **Spreadsheets page** (`pages/Spreadsheets.tsx`): after a document is read, "Use for a task"
   links to `/tasks?csv=<csv_token>` — and carries the document's name along as
   `&name=<file name>` so the task list can say which document's rows are waiting. (The
   endpoint's download response names every attachment `document.csv` and the token map holds
   only bytes, so the API cannot supply the name; the link carries the name the page already
   had, and the API was not changed.)
2. **Task list** (`pages/Tasks.tsx`): with `?csv=` present, one line above the list says
   **"Pick the task to use <file name>'s rows with."** (the sentence lives in `lib/words.ts` as
   `pickTaskForCsv`), shown in both the populated and the empty-list states. Each task's run
   link carries the same `?csv=<token>&name=<name>` along.
3. **Task chooser** (`pages/TaskDetail.tsx`, a small web-only addition): its "Run this task" link
   passes the token through, so the task list's run link reaches the run flow with it intact —
   without this the token died at the chooser.
4. **Run page** (`pages/TaskRun.tsx`): on load with `?csv=<token>`, it fetches
   `/api/v1/documents/to-csv/<token>.csv` as a blob and hands it to **the same `add()` a picked
   file goes through** (the `FormData` → `/api/v1/batches` code), as a file named
   `<document name>.csv` (the `.docx` suffix is dropped; `document.csv` when the link carried no
   name). The person lands on step 2 with the rows loaded, exactly as if they had picked the
   file. The fetch runs once (`carriedIn` ref).
5. **No dead ends:** an expired token or a failed fetch shows one plain sentence in the upload
   area — **"That document's rows are no longer here. Add the Word document again, or pick a
   file."** (`DOCUMENT_ROWS_GONE` in `lib/words.ts`) — and the normal file picker stays usable.
