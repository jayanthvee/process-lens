# PL-008: Recipe Compiler (Phase B)

## Description
Build the compiler engine that turns raw recorded event streams from the extension into an immutable, validated recipe JSON.

## Scope
1. Core compiler module (under `packages/compiler/` or `services/runner/compiler.py`):
   - Ingests raw recorded event streams (clicks, typing, dropdown changes, submits).
   - Coalescing: merges fragmented keystrokes/inputs into single `fill` steps and resolves redundant click/submit pairs.
   - Cleans noise: filters duplicate focus/blur transitions and irrelevant viewport interactions.
   - Parameterization: matches sample input data against recorded literals to generate template variables (e.g. `{{row.email}}`).
   - Assertion inference: infers `assert_after` criteria for commit steps from observed post-action DOM changes.
2. Emits a typed JSON document strictly conforming to `packages/recipe/schema/recipe.schema.json`.
3. Unit tests verifying compilation of real recordings into valid recipes matching schema v1.

## Acceptance Criteria
- Compiled recipes pass `packages/recipe/schema/recipe.schema.json` validation with 0 errors.
- Raw events from PL-007 are successfully folded into clean sequential steps.
- Commit steps require and receive appropriate `assert_after` scaffolding.
- All tests pass with pytest.
- Report written to `internal/agent/reports/PL-008.md`.
