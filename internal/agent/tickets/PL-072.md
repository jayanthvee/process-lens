# PL-072: A Word document becomes a clean CSV (and a run's input)

Owner: T2 (DeepSeek) · Reviewer: T1 · Size: **medium, 3 parts** · Branch `pl-072` · Worktree: whichever DeepSeek
folder is free · API, a cleaning module, web. **No AI** in this ticket.

## Why
Consultants get lists in Word: a client's contact list, a candidate roster, a list of items to update, usually as a
table, sometimes as a bulleted list or as "Label: value" lines. Today ProcessLens takes only `.csv` and `.xlsx`
(`upload_batch` in `services/api/batches.py`). The owner wants a Word file turned into a **clean, tidy CSV**: one to
download, and one to use straight away as a run's input.

## The fix
1. **Reading `.docx`** (new `packages/documents/docx_table.py`; add `python-docx` pinned to an exact version in
   `pyproject.toml`). Three shapes, tried in this order:
   - **A table:** the first table with a header row, or the largest table if several have one. The header row becomes
     the columns. Merged cells are repeated into each cell they cover, and a header split across two rows is joined
     ("Contact" + "Email" gives "Contact Email").
   - **Repeated "Label: value" blocks:** for example `Name: Ana Ruiz / Email: ana@x.test`, separated by blank lines or
     headings. Each block becomes a row, and each label becomes a column.
   - **A bulleted or numbered list:** one column, named from the heading above the list (or "Item").
   - **None of these:** refuse with one plain sentence: "This document has no table or list ProcessLens can read."
   - **Never:** run macros, follow external links, or read embedded objects.
2. **Cleaning** (new `packages/documents/clean.py`, pure functions, deterministic):
   - **Headers:** trimmed and de-duplicated ("Email", "Email 2"); empty headers become "Column N".
   - **Cells:**
     - whitespace collapsed, and non-breaking and zero-width characters removed;
     - smart quotes made plain;
     - emails lower-cased;
     - phone numbers left as typed but trimmed;
     - dates in an unambiguous form (ISO, "12 March 2026", "March 12, 2026") written `YYYY-MM-DD`; ambiguous ones
       like `03/04/2026` are left as typed and counted in a warning;
     - numbers with thousands separators keep their text.
   - **Rows:** fully empty rows dropped; exact duplicate rows dropped, and counted.
   - **A report:** returns `(columns, rows, notes)`, where the notes are plain sentences such as "Removed 2 empty
     rows" or "3 dates were ambiguous and left as typed".
3. **Where it shows up.**
   - **API:**
     - `POST /api/v1/documents/to-csv` (upload a `.docx`, at most 5 MB) returns `{columns, rows (first 50), notes,
       csv_token}`;
     - `GET /api/v1/documents/to-csv/{token}.csv` downloads the full cleaned CSV, UTF-8 with a BOM (so Excel opens it
       correctly). Tokens live in memory or in `.data/`, expire after 1 hour, and never land in logs;
     - `upload_batch` accepts `.docx` too: it runs the same reader and cleaner, then stores the batch as **`csv`** (no
       enum change: the rows are the cleaned CSV), with the notes in the response.
   - **Web:** the Spreadsheets page's add area takes `.docx` as well.
     - After the upload, a preview of the first rows and the notes appear on that same screen.
     - Two buttons sit there: **Download CSV** and **Use for a task**, which continues into the existing
       pick-a-task / check flow.
     - Light theme, gold accent, no engine words.

## Tests first (red before the fix)
- **Fixtures:** `fixtures/documents/` holds four small `.docx` files, generated by a script in that folder so they're
  reproducible: a clean table, a table with merged cells and a two-row header, Label: value blocks, and a bulleted
  list. Plus one with no table.
- **pytest, the reader:** each shape gives the expected columns and rows; the no-table file gives the refusal.
- **pytest, the cleaner:** each rule, including the ambiguous date being left alone and counted, and the duplicate
  and empty-row counts.
- **pytest, the API:** `to-csv` and the download (the BOM, the escaping of commas and quotes); `upload_batch` with a
  `.docx` makes a batch whose rows equal the cleaned rows; a file over 5 MB gives 413; a non-docx renamed `.docx`
  gives 422.
- **vitest:** the preview, the notes, and both buttons.
