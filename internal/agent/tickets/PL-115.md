# PL-115: Tasks and Runs read plainly to someone who has never seen ProcessLens

Owner: T2 (DeepSeek) · Branch `pl-115` (from `main` at the PR #91 merge) · Reviewer: T1

## Why

The side panel is for employees who are not technical. On 2026-10-26/27 the owner used Tasks and
Runs and kept hitting words and states that mean nothing to a person (PL-109 left this pass open).
This ticket fixes the screens a person reads after teaching: the **Tasks** tab, the **Runs** tab and
its list, **Needs your help**, and the header.

## Change (what the owner saw, then the rule)

1. **Task cards name the app, not the address.** Cards read `localhost:8069`, `127.0.0.1:8069`,
   `goodlabs.com`. Show the site's own name when known (the page title's site part recorded while
   teaching, else the host without port and `www.`), e.g. "Odoo" / "goodlabs.com". Never a port.
2. **Default task names are not names.** "Recorded on goodlabs.com", "Recorded task" fill the list.
   On the card, a task whose name is one of the defaults shows "Untitled task · <site>" with a
   **Rename** action on the same card (PATCH the name; the endpoint exists if `services/api` has
   it, otherwise list it under "Needs PL-113/114").
3. **One button per card that says what happens.** "Run with a spreadsheet" stays for spreadsheet
   tasks; a task with no inputs shows "Run"; a sign-in task shows the PL-112 email pick. No card
   shows two run buttons.
4. **Runs list says what each run did, in one line.** Today: "All runs", columns Task / Status /
   Started / Progress, and "This task" when the name is missing. Each row: the task's name, then a
   sentence: "Added 3 of 5 · 1 already done · 1 needs you", "Finished: all 4 done", "Stopped by you
   after 2 rows", "Waiting for you: <the reason>". Times as "today 11:49 PM", "yesterday", dates
   only when older.
5. **"Already there" is the right words for the kind of task.** For a task that adds things: "Already
   added". For a task that changes things: "Already done". For a sign-in: never shown.
6. **Status words** a person sees anywhere in these screens map to these and only these: Waiting to
   start · Running · Waiting for you · Finished · Stopped. "Not paused.", "queued", "preview",
   "completed", "parked", "reconciling", "submitted_unverified" never appear as text.
7. **Waiting for you always says what to do, with the button there.** A run waiting for a decision
   shows the one sentence and its buttons on the run's line in the Runs list too, not only inside the
   run (owner's rule: the action sits where the problem shows).
8. **Time saved** shows only when the run finished with at least one row done: "Saved about 9
   minutes (3 rows × about 3 min by hand)". "By hand: about 3 min a row (estimated)" alone, on a run
   that did nothing, is removed.
9. **Empty and loading states** say what to do next: "No runs yet. Pick a task in Tasks and press
   Run." / "Nothing needs you right now."
10. **Header:** "Not connected" gets the **Connect** button beside it (it exists; make sure it is on
    every tab), and "Connected" is quiet text, not a box that looks like a button.
