# PL-086: Hosted mode: the public address and a team access code

Owner: T1 · Branch `pl-086` (from `main`)

## Why

The first Render deploy failed its health check. The API's front door answers only the local
interface (loopback peer and a local `Host`), and that rule was its only access control. Behind
Render's proxy no caller is local, so every request was refused, health check included. Opening
the door without a replacement would put the dashboard and API on the internet with no sign-in.

## Scope

1. **Hosted mode** turns on when `PROCESSLENS_PUBLIC_URL` or Render's `RENDER_EXTERNAL_URL` is
   set. Local mode is unchanged.
   - The `Host` must be the public address.
   - A loopback peer is not a credential.
   - The public origin counts as the API's own origin for the CSRF check.
2. **Credentials:**
   - the web cookie: an HMAC of `PROCESSLENS_ACCESS_CODE`, set by `POST /api/v1/access`,
     HttpOnly, SameSite=Strict, Secure over https;
   - `Bearer <access code>` (the extension);
   - `Bearer <runner secret>` (the supervisor and the runner).
   - Missing one gives 401 with a plain sentence.
3. **Open without a credential:**
   - `GET /health` (any `Host`);
   - the access routes;
   - the page's own files outside `/api/`.
4. **Sockets:** hosted, only the `Host` check changes. The extension still proves itself with its
   session token, and the runner with its secret.
5. **Deploy:**
   - a hosted `api` refuses to start without `PROCESSLENS_ACCESS_CODE`;
   - `render.yaml` generates the code;
   - the supervisor sends the runner secret.
6. **Web:** a one-card sign-in before the app.
7. **Extension:**
   - `PROCESSLENS_ACCESS_CODE` is baked into handed-out builds (`package` refuses an https build
     without it);
   - a Team access code field under More;
   - the code is sent on its four HTTP calls;
   - a plain message on 401.
   - Fixes the baked address never reaching the address field.

## Gates

- `python -m pytest -q`, `ruff check .`, `ruff format --check .`
- `npm --prefix apps/extension run check`
- `npm --prefix apps/web run check`
