# PL-076: "Use for a task" carries the cleaned CSV over

Owner: T2 (GLM) · Reviewer: T1 · Branch `pl-076` (from `main`)
Time box: 60 minutes

## Why

PL-072 turns a Word document into a clean CSV on the Spreadsheets page. Its "Use for a task"
button only opens the task list, so the person still has to download the file and upload it
again on the task's run page. The owner's rule: no manual juggling. The CSV should already be
there when the person picks the task.

## Scope (web app only: `apps/web/`)

1. `apps/web/src/pages/Spreadsheets.tsx`: "Use for a task" links to `/tasks?csv=<csv_token>`.
2. The task list page: when `?csv=` is present, show one line above the list, "Pick the task
   to use <file name>'s rows with." (use the uploaded document's name; put the sentence in
   `lib/words.ts`). Each task's run link carries the same `?csv=<token>` along.
3. `apps/web/src/pages/TaskRun.tsx`: when `?csv=<token>` is present on load, fetch
   `/api/v1/documents/to-csv/<token>.csv` as a blob and send it through **the same upload path a
   picked file takes** (the `FormData` → `/api/v1/batches` code near line 142). The person
   lands on the column-mapping step with the rows already loaded, exactly as if they had picked
   the file. Name the file `<document name>.csv`.
4. If the token has expired or the fetch fails, show one plain sentence in the upload area,
   "That document's rows are no longer here. Add the Word document again, or pick a file." The
   normal file picker stays usable. No dead ends.

No API changes. If the documents endpoint can't give you the document's name, use
"document.csv" and say so in the report. Don't change the endpoint.

## Gates

- Tests first in `apps/web/tests/`:
  - the Spreadsheets link carries the token;
  - the task list shows the sentence and passes the token on;
  - TaskRun uploads the fetched CSV through the batch upload with no file picked;
  - an expired token shows the sentence and leaves the picker working.
- `npm --prefix apps/web run check` (typecheck, tests, build) and full `python -m pytest -q`
  (it serves `apps/web/dist`).
- No e2e needed.
