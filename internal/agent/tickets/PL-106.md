# PL-106: Plain words for what confused people on the call

Owner: T2 (DeepSeek) · Branch `pl-106` (from `main`) · Reviewer: T1

## Why

A pilot tester (a PM, not technical) and the owner used the product on a live call. Each item below
is a moment where a normal person got stuck or misread the screen. None is a new feature. The owner's
standing rule holds: the explanation or the action sits where the problem shows, on the same screen.

PL-105 moves the employee screens into a Chrome side panel by reusing the React pages in `apps/web`.
So fix each thing where it lives today (`apps/web` pages and `lib`, `apps/extension/src/popup`); the
panel picks the fixes up.

The failing tests are already on this branch. Make them pass. Do not change what they assert.

## Change

### 1. Say why "Save as task" is greyed out

`apps/extension/src/popup/make-recipe.ts`, `createMakeRecipeForm` → `syncGo()` disables the button for
three reasons: no events, `busy`, or no key column chosen (`keyEl.value` is empty). An empty key has two
causes: no value was typed while teaching (`recordedValues(events)` is empty, so the select has no
options), or there are values but no default key and the person has not picked one.

- Add `<p class="panel__note" id="make-go-why">` in `popup.html`, directly after `#make-go`.
- `syncGo()` writes one sentence there, first match wins:
  - no events: "Record some steps first."
  - no recorded values: "Type at least one value while teaching, so each row has something to fill in."
  - no key chosen: "Pick the column that identifies each row."
  - otherwise (or while `busy`, which already shows the saving note): empty.
- Keep the sentences in `apps/extension/src/popup/words.ts` as exported constants.

### 2. Re-check the rows the moment a column changes

`apps/web/src/pages/TaskRun.tsx`, `TaskRun`: the select's `onChange` only updates `edits`. The row
problems (`rows_need_a_look`) only refresh in `continueOn()`, which saves the mapping and asks
`/check` again.

- On a select change, do the same save-and-ask straight away (PUT `/batches/{id}/mapping`, then GET the
  check), stay on step 2, and show the new answer. Pull the shared part out of `continueOn()`.
- Keep the person's pick on screen while the answer is in flight. If two changes overlap, only the
  latest answer is shown (ignore a stale response).
- Continue keeps working as today.

### 3. Do not guess a column whose values do not fit the field

`services/api/batches.py`, `_match` / `_mapping_for` (called by `check_batch`): `_rank` matched the
file column "Expected" to the field `expected_revenue` because the names share a word. The values were
"verified" and "skip", so every row was then flagged "isn't a number".

- Rule: when a field has a kind (`kinds.kind(example)` is `number` or `email`), a spreadsheet column is
  not auto-matched to it if most of that column's non-blank values do not fit that kind (more than
  half fail `kinds.is_email` / `kinds.number_value`). The field then reads "Not found" and the person
  picks.
- This needs every row's value for the column, not just `row_one`. Pass the rows into `_mapping_for`.
- It applies to the guess only. A saved mapping (`_with_saved`) always wins.
- A column where most values fit is still guessed, and the stray value is still flagged as before.

### 4. "Finished" with rows that need a person

`apps/web/src/lib/words.ts`, `runStatusWords(status, chromeAttached?)`: a completed run reads
"Finished" whatever its counts. Beside "11 of 15 done" it reads like a clean finish.

- Add a third argument, the run's counts. A `completed` run with `parked + failed > 0` reads
  "Finished — N need you" ("1 needs you"), tone `help`. Otherwise "Finished", tone `ok`.
- Pass the counts where a run's counts are at hand: `Runs.tsx`, `RunDetail.tsx`, `TaskDetail.tsx`.
  (`Home.tsx` `taskResult` already says "N needs help" for a finished run; leave it.)

### 5. "0 m time saved" next to 145 rows

`apps/web/src/pages/Home.tsx`, the saved figure uses `durationWords(savedSeconds / 60)`, which rounds
20 seconds to "0 m".

- Decision: under one minute, the figure reads "Under a minute". Do it in `Home.tsx` (or a new words
  function); leave `durationWords` as it is, its other callers are fine.

### 6. A value with a line break "did not stick"

`apps/extension/src/executor/dispatch.ts`, `dispatchFill`: after `Input.insertText` it compares
`readFieldValue(...)` with the typed value exactly. A spreadsheet cell with CRLF types `"Ana\r\nRuiz"`;
a textarea holds `"Ana\nRuiz"` and a one-line input holds `"AnaRuiz"`, so the row parks.

- Compare the way the browser stores it: in the typed value, turn `\r\n` and `\r` into `\n`. Accept the
  field when it equals that, or, for a one-line field, equals it with the line breaks removed.
- A field that kept something else is still "did not stick".

### 7. "Not found" is a skip, not "needs help"

`packages/compiler/compiler.py`, `_not_found_branch` (PL-077): an update whose search finds nothing
ends `parked` with "No record matched …", so it lands in Needs help. There is nothing for a person
to do.

- The branch ends `skipped`, named "Skip a record when the search finds nothing", reason
  "Not found in <host>." where `<host>` is the host of the page the search ran on (for example
  "Not found in crm.example.com."). Update the compile warning to match.
- Ledger: no change needed. The branch runs after the search and before any commit, so the record is
  in `filling` with `commit_attempted` false, and `filling → skipped` is legal for exactly that
  (migration 0003, `LEDGER_SPEC.md`). `run_loop.py`'s `end_record` already turns a commit-attempted
  skip into a park (B2). If you find a path where the record is not in `filling` or `prechecked` at
  this branch, stop and write it in the report; do not change the ledger.
- `apps/web/src/lib/words.ts`, `rowOutcome(state, reason?)`: a `skipped` row whose reason starts with
  "Not found in" reads "Skipped"; any other skipped row keeps "Already there". `plainReason` already
  shows the reason as written.
- `apps/extension/src/popup/make-recipe.ts`: `PARK_WHEN_NOTHING_FOUND` becomes
  "Skip a row when the search finds nothing".

### 8. Say how to connect Chrome

The website says Chrome is not connected without saying what to do, or says "press Connect".

- `apps/web/src/lib/words.ts`: export
  `CONNECT_CHROME = "Click the ProcessLens icon in Chrome's toolbar to connect."`
- Use it in: `shell/Sidebar.tsx` (a line under "Chrome not connected", inside `.side-foot`, only while
  not connected), `pages/Apps.tsx` (`CHROME_AWAY` becomes "Chrome isn't connected. " + it),
  `WAITING_FOR_CHROME` ("Waiting for Chrome. " + it), and the `executor_disconnected` pause reason.
