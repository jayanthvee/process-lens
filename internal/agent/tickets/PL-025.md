# PL-025: The extension popup in the app's design language

Owner: T2 · Reviewer: T1 · Depends on: PL-023 (merged) · Phase: D

## Description
The Chrome extension's popup is what a person sees while teaching a task, so it must look and speak like the
web app. Apply `internal/docs/DESIGN.md` to `apps/extension/src/popup/`: Public Sans, the light fog, glass
surfaces, the gold primary button, and the plain words. This is a restyle and re-wording. **No behaviour
changes.**

## Requirements
1. **Look.**
   - The tokens are a copy of the web app's `tokens.css`, under `apps/extension/src/popup/`.
   - **Light only.** Popup width stays as it is now.
   - Public Sans is **bundled with the extension** (`@fontsource/public-sans` woff2 files copied into `dist`).
     The extension's CSP must not load remote fonts.
2. **Words.** Use the DESIGN.md §2 vocabulary.
   - "Make recipe" → **"Save as task"**.
   - "record key" → **"Which column identifies each row?"**
   - "allowed origins" → **"Sites this task may use"**.
   - Recorder warnings are rewritten as plain sentences.
   - Show steps as plain sentences: "Typed the email", "Clicked Save".
3. **The layout, top to bottom:**
   - connection status ("Connected to ProcessLens" or "Not connected");
   - the big **Start teaching** / **Stop** button;
   - the live list of recorded steps;
   - after stopping, the Save-as-task form with one gold primary button.
4. **The e2e contract is frozen.**
   - Every element id, `data-state` value and `data-testid` the e2e harness uses must keep its exact name and
     meaning: `#start`, `#stop`, `#clear`, `#state`, `#session-state`, and the make-recipe form's ids. Grep
     `tests/e2e/conftest.py` and the e2e tests for every selector, and list them in the report.
   - Only text and styles change.
5. **Tests.**
   - Update the popup vitest expectations for the new wording.
   - Add the same engine-word check as PL-023 requirement 7, run over the popup's rendered text.

## Out of scope
Recorder, executor and service-worker logic. The web app.

## Acceptance criteria
- [ ] `npm --prefix apps/extension run check` passes: typecheck, test, build and validate.
- [ ] The report lists every e2e selector and confirms it is unchanged. T1 runs the e2e tests and looks at the
  popup.
