# PL-005: CI guards for the constitution

Owner: T2 DeepSeek · Critical: no · Depends on: PL-001, PL-002 · Phase: 0

## Goal
Constitution rules 4, 5, 16, 17, 19, 20 and the protected-paths rule fail CI when violated.

## Read first
- internal/AGENTS.md, internal/docs/ARCHITECTURE.md (the YAML dependency block)

## Scope
- tools/guards/ (including `boundaries.yaml`, copied from the YAML block in internal/docs/ARCHITECTURE.md)
- .github/workflows/ (add jobs; keep `permissions: contents: read`)
- Lint configuration files at the root
- internal/agent/reports/PL-005.md

## Requirements
1. Import boundaries from the ARCHITECTURE.md YAML block: Python via import-linter, TypeScript via
   eslint `no-restricted-imports`. Model SDKs (anthropic, openai, google-genai, deepseek clients)
   importable only from services/ai.
2. Protected public paths: existing files in db/migrations may never change. A pull request that changes
   packages/recipe/schema/ fails unless it carries the label `decision-approved` (the owner adds it after
   recording the decision privately).
3. No fixed sleeps in services/runner and apps/extension: forbid `time.sleep`, `asyncio.sleep` with a
   constant, and `setTimeout`-based waits (allow-list comments only with a ticket reference).
4. No use-case names (crm, invoice, candidate, enrollment, appointment, reconciliation, ...) in services/runner.
5. Deny-list of stealth and captcha-solving packages in all dependency manifests.
6. Leak guard: CI fails if any tracked file mentions `internal/`, a ticket id pattern (`PL-` followed by digits),
   or contains the pointer files (`.gitignore` is exempt). Scan commit messages in the pull request for the same.

## Acceptance criteria
- [ ] For each guard, a deliberate violation on a scratch branch fails CI. Paste the failing output.
- [ ] Main is green with all guards enabled.
