# PL-029: Dashboard fixes from the PL-023 review

Owner: T2 (GLM) · Reviewer: T1 · Size: small

## Do exactly these four fixes
1. **A route with a dot 404s on refresh.** In `services/api/main.py`, `SpaStaticFiles.get_response` treats any
   path with a suffix as an asset, so refreshing `/runs/abc.def` gives 404. Change it so a path is treated as an
   asset only when its suffix is one of: `.js .css .map .png .jpg .jpeg .svg .ico .webp .woff .woff2 .txt .json`.
   Any other path answers `index.html`. An API path keeps its 404.
2. **Queued runs show as "Running now".** In `packages/ledger/reads.py`, the Home `running` read includes runs that
   have not started. Show only `status = 'running'`. Queued runs aren't listed there.
3. **A developer message on Needs help.** When `/api/v1/operator` answers 503, the page shows its detail text,
   which names `PROCESSLENS_OPERATOR_ID`. Show instead: "Actions are turned off until an operator is set up. Ask
   your admin." Find the place with `grep -rn "operator" apps/web/src`.
4. **A slow Home count.** Add `db/migrations/0007_transitions_at_index.sql` with one line:
   `CREATE INDEX IF NOT EXISTS run_record_transitions_tenant_at ON run_record_transitions (tenant_id, at);`.
