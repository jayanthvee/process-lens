# PL-034: Say what the demo is doing, and one admin grant tidy-up

Owner: T2 (DeepSeek Flash) · Reviewer: T1 · Size: **small** · Branch: `pl-034` (cut from `pl-030b`, which carries
the demo.py import fix)

## Why
1. In the owner's demo, Try one row sat on "Queued" because Chrome wasn't connected, and the `demo.py` window said
   nothing. The terminal should say what is happening.
2. Review follow-up from PL-026: `processlens_admin` may write `tenants.min_extension_version` directly, but ADM-001
   sends that write through the API. There should be one path, not two.

## Do exactly this
1. **`scripts/demo.py` prints each change of state, once, in plain words:**
   - "Chrome is connected." / "Chrome is not connected: open the ProcessLens extension and press Connect."
   - "A run is waiting for Chrome." (a run is open and there is no session)
   - "Started a runner for run <first 8 chars of id>."
   - "The runner finished." (exit code 0) / "The runner stopped with code <n>." (otherwise)

   Put the wording in a **pure function**, `status_lines(previous: State, current: State) -> list[str]`, where
   `State` is a small dataclass: `session_attached: bool`, `waiting_run: str | None`,
   `worker_running_for: str | None`, `last_exit: int | None`. The supervisor loop builds a `State` every tick and
   prints whatever `status_lines` returns. It never prints the same line twice in a row.
2. **`db/migrations/0008_admin_grant_tidy.sql`:** `REVOKE UPDATE (min_extension_version) ON tenants FROM
   processlens_admin;` with a one-line comment saying why: the admin panel sets it through the API.
   - Update the grant assertions in `tests/db/test_admin_migration.py` and the expected list in
     `tests/db/test_migration_runner.py`.
   - Update `internal/docs/ADMIN-MODULES.md` wherever it lists that grant.

## Tests (write them first)
- `tests/demo/test_demo.py`:
  - each transition gives the exact sentence;

- `tests/db/test_admin_migration.py`: `processlens_admin` cannot update `tenants.min_extension_version` (use
  `SET ROLE`, as the file already does).
