# PL-084: the run page works for a 500-row run

Owner: T2 (DeepSeek) · Reviewer: T1 · Branch `pl-084` (from `main`)
Time box: 120 minutes

## Why

T1 watched a real 500-row run on Odoo from the run page (`apps/web/src/pages/RunDetail.tsx`),
the screen an employee stares at while a batch goes. Here's what an employee would trip on:

- **Rows aren't in sheet order:** the list goes 129, 003, 186, 030… Nobody can find "their"
  row.
- **Rows show the internal key, lowercased** ("scale customer 129"), not what the sheet says
  ("Scale Customer 129").
- **Done rows say "Assertion passed."**, which is the ledger's word, not a person's.
- **"Not paused." is always on screen.** It's noise when nothing is paused.
- **All 500 rows sit in one long table** with no way to see "just the ones that need me" or
  find one customer.
- **At 1024 px wide the page runs off the right edge:** the Search box and the Reason column are
  cut off.

## Scope

1. **Sheet order.** The records list is ordered by the input row's position in the sheet
   (`input_records`'s row index). Fix it in the API query (`services/api/runs.py`, the records
   endpoint) and follow `internal/docs/sql-patterns.md`. Don't sort in the browser.
2. **The sheet's own value.** Each row shows the sheet's value for the record-key column from
   the clean row, as the person typed it. Fall back to the key only when that value is missing.
   Add the field to the records response; don't remove `record_key`.
3. **Plain reasons.** Map the ledger's reasons to words a person reads, in `lib/words.ts`:
   - "assertion passed" → **"Saved."**
   - "already committed in an earlier run" → **"Already done in an earlier run."**
   - For every other reason the ledger or runner writes, grep `packages/ledger` and
     `services/runner` for the reason strings and map each one that a person could see. Anything
     unmapped shows as it is today.
4. **The pause line** shows only while the run is paused.
5. **Filter tabs and a search** above the table: All, Needs help (parked or failed), Done
   (verified or skipped), and Waiting. Each tab shows its count, from the run's `counts`. Add one
   search box that filters by the row's shown value. Over 200 rows in the current tab, show the
   first 200 and a "Show all" button. This keeps the page light at 2,000 rows (the upload limit).
6. **Width.** No horizontal scroll from 1024 px wide down to 768. The Reason column wraps; it's
   never cut off.

## Gates

- Tests first:
  - an API test that the records come back in sheet order with the sheet's value;
  - web tests for the reason words, the pause line, each tab's filter and count, the search, and
    the 200-row cap with "Show all".
- `npm --prefix apps/web run check` and full `python -m pytest -q`.
- No e2e.
