# PL-082: the extension popup shows one step at a time, in plain words

Owner: T2 (DeepSeek) · Reviewer: T1 · Branch `pl-082` (from `main`)
Time box: 120 minutes

## Why

We're about to hand ProcessLens to a real employee, and the owner's verdict is that it's "very
very hard to use". The popup is the first thing they touch. T1's walkthrough on `main`
(screenshot in the review notes) found:

- **All three steps show at once:** Teach, an empty Save form, and "Open in ProcessLens" for a
  task that doesn't exist yet.
- **It scolds before anything has happened:** "I couldn't check for duplicates because you
  didn't search first."
- **Technical questions up front:** "Which column identifies each row?", "Sites this task may
  use", "Stop and ask me if one of these is empty".
- **"Clear the steps" looks as important as "Start teaching".**
- **It's about 1,040 px tall.** Chrome caps a popup at 600 px, so people scroll inside a small
  window.

## What it should be (`apps/extension/src/popup/`)

One screen per moment, each fitting in **380 × 560 px with no scrolling**. Exactly one primary
(gold) button per screen.

1. **Not connected.** One sentence, "ProcessLens isn't open on this computer.", with a quiet
   "Try again" button. Keep the hub address field under "More".
2. **Ready to teach.**
   - The title "Teach a task", then one sentence: "Open the app you want to automate in this
     tab, then press Start. Do one row by hand, exactly as you normally would."
   - The primary button: **Start teaching**.
   - Nothing else, apart from the quiet "More" at the bottom.
3. **Teaching.** A red recording dot with "Watching… do one row, then press Done." Show the
   steps as a short live list of the last 5 steps, with a count ("12 steps"). The primary
   button is **Done**, which is today's Stop; "Start over" is a quiet text link.
4. **Name it.** One field, "What is this task called?", already filled with a good guess, then
   the primary **Save task**. Everything else goes behind a closed "Options" disclosure, and
   each option is worded as a question a person would ask:
   - "Which column tells rows apart?" with the record key select, defaulted well;
   - "Skip a row that's already there?" with the duplicate rule. Show its hint only after the
     person opens Options, and never as a warning;
   - "Stop and ask me if one of these is empty";
   - the sites list.
5. **Saved.** "Saved. Open it in ProcessLens to try one row, then run the rest." The primary
   button is **Open in ProcessLens**, plus a quiet "Teach another".

Rules:
- **Keep every element `id`** the e2e harness drives (`start`, `stop`, `clear`, `make-name`,
  `make-key`, `make-duplicate`, `make-origins`, `make-park-fields`, `make-go`, `make-result`,
  `open-task`, `hub`, `connect`, `disconnect`, `session-state`, and the rest in `popup.html`).
  Move them between screens and relabel them, but don't rename or remove any. Grep
  `tests/e2e` for every id you touch.
- Show and hide screens on the state the popup already tracks. Don't add new background state.
- The look follows `internal/docs/design/` and the web app: the Public Sans font, near-black
  text, a gold primary, frosted panels, and no pills or uppercase mono labels. All copy goes in
  one place.
- No change to what is recorded or compiled.
