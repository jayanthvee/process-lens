# PL-003: Demo CRM with drift switches

Owner: T2 DeepSeek · Critical: no · Depends on: PL-002 · Phase: 1

## Goal
A realistic, synthetic CRM website the executor will be built and tested against, including switches that
simulate the site changing.

## Read first
- internal/AGENTS.md (constitution 21: synthetic data only)

## Scope
- apps/demo-crm/
- internal/agent/reports/PL-003.md

## Out of scope
- Everything outside apps/demo-crm.

## Requirements
1. Vite + React + TypeScript frontend (port 5173); FastAPI + SQLite API in `apps/demo-crm/server` (port 8001).
   `npm run dev` in apps/demo-crm starts both.
2. Login page: any username and password; sets a session cookie.
3. Customers page: search box labelled "Search customers" (matches email or name), results table,
   "New lead" button.
4. Form titled "New lead": Full name, Email, Phone, Interest, Preferred time, Assigned to, Notes.
   Interest and Assigned to are custom dropdowns (`role="combobox"` with a `role="listbox"`), not `<select>`.
   All inputs are React controlled inputs. Every control has an accessible label.
5. Save shows the toast "Lead created" only after the API responds. A duplicate email shows
   "A lead with this email already exists".
6. Test API: `GET /api/leads?email=` and `POST /api/test/reset` (wipe and reseed 10 synthetic leads,
   `example.com` emails, 555 numbers).
7. Drift switches via URL query parameters, remembered in sessionStorage:
   `drift=rename_save` (button reads "Save lead"), `drift=required_company` (adds a required Company field),
   `slow_save=<ms>`, `session_expired=1` (next action redirects to login).
8. README in apps/demo-crm with run instructions and the switches.

## Acceptance criteria
- [ ] `npm run dev` starts both servers; README steps work from a clean checkout.
- [ ] A Playwright smoke test creates a lead, checks the toast, and confirms it via the test API.
- [ ] Each drift switch is covered by a Playwright test.
- [ ] Lighthouse or axe accessibility check: every form control has an accessible name.
- [ ] No file outside apps/demo-crm changed.
