# PL-009: Recorder Observer & Post-Action Telemetry

## Description
Extend `apps/extension` to capture DOM mutations and navigation observations immediately following interactions, enabling automated `assert_after` inference in the compiler.

## Scope
1. MutationObserver in `apps/extension/src/content/recorder.ts`:
   - Debounce and observe DOM insertions/removals for 1500ms following `click` and `submit` events.
   - Capture appearance of high-signal confirmation elements (`[role="alert"]`, `.toast`, `.notification`, heading changes).
   - Capture page URL mutations (`pushState`, `replaceState`, hashchange).
2. Fix `apps/extension/src/shared/fingerprint.ts`:
   - Suppress `text_fuzzy` calculation for input/textarea elements when the value matches the typed buffer.
3. Contract conformance:
   - Emit `observation` event types matching compiler expectation in `packages/compiler/assertions.py`.

## Acceptance Criteria
- Live extension capture records both action events and corresponding post-action DOM observations.
- Compiler accepts raw observed events and successfully generates `assert_after` without manual `commit_assertions` overrides.
- All unit and e2e smoke tests pass.
- Report written to `internal/agent/reports/PL-009.md`.
