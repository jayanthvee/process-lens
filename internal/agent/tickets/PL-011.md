# PL-011: Recipe Storage and Ingestion API

## Description
Implement the FastAPI endpoints for storing, retrieving, and validating compiled recipe documents in the backend database.

## Scope
1. Recipe endpoints in backend service:
   - `POST /api/v1/recipes`: Accepts a compiled recipe JSON payload, validates it against `packages/recipe/schema/recipe.schema.json`, extracts meta fields (name, record_key, idempotency_key), and persists it to the `recipes` table.
   - `GET /api/v1/recipes`: Lists active recipes.
   - `GET /api/v1/recipes/{id}`: Retrieves recipe by ID with version pinned.
2. Invariant enforcement:
   - Fail-closed validation: Reject any recipe that does not pass schema validation.
   - Verify all commit steps contain valid `assert_after` definitions.
3. Unit tests with pytest covering valid insertion, schema violation rejections, and retrieval.

## Acceptance Criteria
- All endpoints functional and tested with `pytest`.
- 100% schema validation enforcement on ingest.
- Report written to `internal/agent/reports/PL-011.md`.
