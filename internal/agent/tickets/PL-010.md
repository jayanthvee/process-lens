# PL-010: Attended Recipe Executor using chrome.debugger

## Description
Implement the recipe execution engine inside `apps/extension/src/executor/` using the Chrome DevTools Protocol (`chrome.debugger`) to replay compiled recipes against active user sessions.

## Scope
1. Attach and session management:
   - Attach `chrome.debugger` to the active target tab (`debugger` permission from PL-007).
   - Detach cleanly on recipe completion, manual stop, or unrecoverable error.
2. Target resolution engine:
   - Implement the 5-rung target ladder resolver inside the target page context:
     - Rung 1: Accessibility role + accessible name within parent container.
     - Rung 2: `data-testid` / `data-test`.
     - Rung 3: Label association.
     - Rung 4: Stable CSS selector.
     - Rung 5: Fuzzy text match.
   - Support `within` scoping (forms, dialogs, sections) and frame navigation.
3. CDP Event Dispatch:
   - `fill`: Focus element, select existing text, clear, and dispatch `Input.dispatchKeyEvent` for realistic keystrokes.
   - `click`: Scroll element into view, compute box center, dispatch `Input.dispatchMouseEvent` (mousePressed, mouseReleased).
   - `select`: Locate `<select>` option and dispatch value update.
   - `navigate`: Navigate target frame or tab to target URL.
4. Assertion verification:
   - Evaluate `assert_after` criteria (`text_visible`, URL patterns, element presence) with polling up to `timeout_ms`.
   - Fail-closed: Stop execution if post-condition assertion fails.
5. Runner status & control messaging:
   - Provide Start / Pause / Abort execution controls via extension messaging.

## Acceptance Criteria
- Unit tests cover ladder resolution, step dispatching, and assertion timeouts.
- Executor successfully replays a compiled recipe against a live Chromium tab.
- All tests pass (`npm run check` and `pytest`).
- Report written to `internal/agent/reports/PL-010.md`.
