# PL-103: The recorder forgives a normal person's mistakes

Owner: T1 · Branch `pl-103` (from `main`)

## Why

On the pilot call every recording a real person made had something in it our tests never do: a
click on the empty form, Tab between fields, a switch to a tab that was open before the install,
teaching started after New was already pressed. Each one either recorded nothing, recorded a step
that cannot replay, or made the whole save fail with a schema error the person could not read.

The rule from here: a mistake while teaching is cleaned up by the recorder, or shown next to the
step with a one-click fix. It never blocks the save with no reason.

## Change

1. **Open tabs.** Start teaching on a tab that has no recorder yet puts the recorder in
   (`chrome.scripting.executeScript`, all frames; adds the `scripting` permission) and starts. The
   refresh line shows only when that fails. A tab the person switches to while recording gets the
   recorder the same way.
2. **Empty space.** A click on an element with no role of its own that holds form fields, or whose
   only name is a long run of page text, is not a step.
3. **Tab.** Tab from a plain text field is not a step: the next field is filled by its own step.
   Tab from a field whose suggestion list is open is still a step (in Odoo it picks the suggestion).
4. **Names.** Every step name and target name is cut to 120 characters, so no page text can make a
   step the server's schema refuses.
5. **Check before saving** (popup today, the side panel after PL-105). After Stop, each step that
   cannot replay gets one plain line and a fix button on its own row:
   - "This click lands on empty space" → Remove
   - "Teaching started on a form that was already open" (first step is typing, no click or page
     change before it) → "Record again: start on the list and press New while recording"
   - "Nothing was typed, so a spreadsheet has nothing to fill" (only when the person picked
     "Run with a spreadsheet")
6. **The server never refuses a whole save for one step.** A step the schema refuses comes back with
   its step number and a plain reason, shown on that step's row, not under More → Notes for support.
7. **Clumsy-user e2e.** One e2e test per call mistake on the Odoo lead form: stray background click,
   Tab between fields, the kanban quick-add card, a tab open before install, start after New. Each
   must end in a task that runs one row correctly, or in the plain line from item 5.
