# PL-060: A recipe remembers how long the person took to do one row by hand

Owner: T2 (DeepSeek Flash) · Reviewer: T1 · Size: **small, 1 part** · Branch `pl-060` · Worktree
`C:\Users\vasup\process-lens\.worktrees\deepseek` · **Compiler and recipe schema only.** PL-061 (next) shows it on
screen.

## Why
The brief asks for a manual-versus-automated time comparison. Today "time saved" is a guess: 3 minutes for every
finished row, hard-coded in `services/api/home.py` and `apps/web/src/pages/RunDetail.tsx`. We already have the real
manual time: the person did one row by hand while ProcessLens recorded. Every recorded event carries `at` (an ISO
timestamp, `makeEvent` in `apps/extension/src/shared/events.ts`).

## The fix
1. **Schema.** Add an optional `manual_seconds_per_row` to `meta` in `packages/recipe/schema/recipe.schema.json`: a
   number, minimum 1, maximum 86400, described as "How long one row took the person by hand, measured from the
   demonstration." Keep `additionalProperties: false`; it's a declared optional property. Update the TypeScript
   type in `apps/extension/src/shared/recipe-types.ts` only if the schema-conformance test requires it (one line).
2. **Compiler.** In `compile_recording`, measure the **entry the recipe was built from**: from the first kept event's
   `at` to the commit's own `at`, or to the last kept event when there's no commit. Use the same events that survive
   trimming (PL-042/PL-044), not the whole recording.
   - Round to whole seconds, minimum 1.
   - Leave the field out when fewer than two kept events have a parseable `at`, or when the span is negative or over
     a day. No warning when it's left out; the screen falls back.
   - Add a compile warning: "one row took about N seconds by hand".

## Tests first (pytest, red before the fix, new `packages/compiler/tests/test_pl060.py`)
- **Measured:** events 0, 20, 95 and 130 seconds apart, with the save at 130, give `manual_seconds_per_row == 130`.
- **Trimmed:** a two-save recording trimmed to its first entry measures only that entry.
- **Left out:** missing or garbage `at` values leave the field out and the compile still succeeds.
- **Clamped:** a span under 1 second gives 1, and a span over a day leaves the field out.
- **Valid:** the compiled recipe validates against the schema (`assert_valid_recipe`).
- **No regression:** the existing compiler tests pass unchanged. If a test compares the whole `meta`, update only that
  comparison and say so in the report.
