# ProcessLens internal workspace

Private repository, nested inside the public `process-lens` folder and gitignored by it.
Holds everything that must not be public: constitution, design, decisions, board, tickets, reports.

Local setup expects two pointer files in the public repo root (both gitignored there):

- `CLAUDE.md` containing `@internal/AGENTS.md`
- `AGENTS.md` containing `Read internal/AGENTS.md in full before doing anything else, and follow it.`
